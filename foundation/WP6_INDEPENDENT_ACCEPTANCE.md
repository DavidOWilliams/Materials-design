## Findings and scientific claim disposition

- **WP6-R1 / P1 — ACCEPTED BOUNDED LIMITATION; DEFERRED EVIDENCE.** Feedback-on control: four evaluations, three proposals, eight refinement solves, one feasible candidate; feedback-off: two evaluations, one proposal, four refinement solves, zero feasible. Matching maximum proposal slots do **not** equate actual effort. Common-prefix initial comparisons cannot establish revision superiority. Existing WP4 demonstrates an estimated manufacturing response and candidate revision within its scenario; WP6 only evaluates those bounded responses and does not identify a causal equal-effort advantage. P1 owns the stronger claim.
- **WP6-R2 / P2 — ACCEPTED BOUNDED LIMITATION; DEFERRED EVIDENCE.** Held-out case changes duty-description identity/brief hash, but **not** numerical physics. Tight-mass and layer/feed cases are sensitivity/constraint tests, not generalisation evidence. P2 separates parameter interpolation, unseen qualified architectures/material packs, and genuinely new physics.
- **WP6-R3 — BOUNDED PASS with remaining challenge evidence classified for future rigor.** Execute/report honest no-feasible, corrupted dossier, invalid budget, cancellation, unsupported edits. A test asserting stop reason in `{no_improvement_possible, evaluation_budget_exhausted}` is **not proof** no-improvement stop occurred. A dedicated forced numerical unresolved-quality qualification is **not established**. These explicit gaps are retained for WP7 release documentation or later challenge strengthening; neither may be relabelled passed.
- **WP6-R4 — PASS for application replay integrity, NOT external scientific model validation.** Nine dossiers replayed in fresh process via existing WP5 verifier. P2 owns independent published numerical benchmarks.
- **P3 — DEFERRED EVIDENCE, NOT WP6 BLOCKER.** All nine cases `measured_evidence=null`. Intended, estimated-achieved and measured states must remain separate. No measured ceramic validation, uncertainty assessment or V1 qualification.
