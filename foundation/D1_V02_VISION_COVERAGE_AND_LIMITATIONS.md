# D1 v0.2 — Vision coverage and scientific limitations

D1 v0.2 is a **synthetic ceramic coupon demonstration**, not the general material-system discovery and optimisation capability described by the enduring Vision v3.0. No experimental qualification, process measurement, external candidate discovery or real manufacturing physics was added in this interface iteration.

| Guided Vision stage | Supported in D1 v0.2 | Not implemented / scientific boundary |
|---|---|---|
| 1. Define challenge | Synthetic fixed catalogue, configurable mass ceiling, mesh, process resolution, budget; immutable optional brief snapshot | Arbitrary real engineering requirements, external specifications, real material records |
| 2. Propose designs | WP3 deterministic bounded homogeneous, layered and gradient architectures | General discovery, inverse model generation, arbitrary constituents and 3D geometry |
| 3. Evaluate intended-state performance | Accepted WP2 numerical calculations via WP3 with objective charts, exact tables and intended-state Pareto | Fully qualified thermo-mechanical/experimental validation |
| 4. Evaluate manufacturing | WP4 A/B gradient only; synthetic process mapping and estimated achieved-state numerical evaluation | Measured manufacturing achieved state; mixing lag, shrinkage, sintering, CFD, porosity, validated process physics |
| 5. Feedback and revision | Accepted bounded density-guided mass constraint rule where triggered; recorded parent hashes and stop states | General optimisation, universal revision search, guaranteed improvement |
| 6. Compare alternatives | Independent WP3 and WP4 objective scatter plots and eligibility tables | Cross-context Pareto pooling; unsupported physical feasibility claims |
| 7. Preserve evidence | WP3 portable verified ZIP; WP4 immutable dossier and separate handoff companion; replay, import, journal recovery | One combined relocatable WP3+WP4 dossier; external experimental traceability |

## Two connected evaluation branches

The Vision distinguishes **material-system intended performance** from **manufacturing-process / estimated-achieved performance**. D1 maintains this separation rigorously.

- WP3 intended-state numerical Pareto membership cannot be promoted to manufacturing qualification.
- WP4 estimated-achieved-state Pareto is conditional on the accepted synthetic scenario and common comparison context; not a measured Pareto population.
- A visual profile overlay is permitted only when saved constituent basis, architecture class and coordinate system support it. Distinct layered interfaces cannot be silently joined, and no interpolated achieved measurements may be invented.
- The achieved-state model excludes physically important mechanisms and is explicitly labelled as an estimate.
- An accepted synthetic calculation or green eligibility indicator is **not** physical or experimental validation.

## Usability interpretation and open improvements

D1 v0.1.0 required users to read JSON and developer-centric controls. v0.2 replaces several primary presentations with objective scatter plots, component-position diagrams and guided labels, while preserving expandable raw data.

The v0.2 design remains based on the four inherited Streamlit tabs rather than a fully implemented seven-stage navigation system. Candidate selection is via adjacent selectable ID, not direct scatter-click linking. The architecture strip is a structural/interval indicator, not a computed spatial microstructure image. A1 profile and A2 exact table are combined as chosen by the programme owner; C1 overlay/C3 matched-coordinate difference only appear if supported by actual saved source data.

Before independent acceptance, reviewer must inspect actual screenshot evidence and match chart values to verified source rows. The independent gate must not infer a new science capability from a clearer UI.
