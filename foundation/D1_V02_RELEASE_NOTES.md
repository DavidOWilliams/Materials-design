## Change from v0.1.0

D1 v0.2 improves **presentation and guided first use**, not scientific model capabilities. Added source-preserving architecture/constituent composition graphics for WP3 homogeneous, layered and gradient designs; objective scatter plots with source-matched coordinates and uncertainty/eligibility status; separate WP4 estimated-achieved feedback/deviation presentation only when genuinely supported by matching data; expanded source tables and text explanations; existing-dossier collision protection and suggested new unused file names. Dedicated Chromium/browser and source-data tests are retained.

WP3 intended-state and WP4 estimated-achieved Pareto populations are **separate, never pooled**. The guided four-tab UI is not a complete seven-stage redesign; scatter-point direct click-to-select is not implemented. Unavailable/nonfinite and unsupported overlays must be shown as unknown/unavailable, not invented, interpolated as measurements or promoted to qualified evidence.
